## ✨ 现在能做什么

### ✅ 能做的（可以试试）

1. **查看完整的测试套件**
   ```bash
   cd ecommerce-agent-framework
   pytest tests/ -v  # 看到 52/52 通过
   ```

2. **查看意图分类的工作**
   ```bash
   # 查看 13 个单元测试的详细结果
   pytest tests/test_intent_parser.py -v
   ```

3. **查看不确定性检测的细节**
   ```bash
   # 查看 28 个测试的完整覆盖
   pytest tests/test_uncertainty_detector.py -v
   ```

4. **生成 Ground Truth 数据**
   ```bash
   python experiments/generate_ground_truth.py
   # 输出：217 个精心标注的测试用例 JSON
   ```

5. **尝试跑基线实验**（虽然还是 demo 输出）
   ```bash
   python experiments/run_llm_only.py --sample-size 10
   python experiments/run_vanilla_rag.py --sample-size 10
   ```

### ⚠️ 还不能做的

1. **向 API 发起真实查询**
   - API 框架已完成 50%

2. **问价格/库存问题**
   - 这需要 SQL 数据库支持（当前只有向量库）
   - 混合查询逻辑还未实装

3. **进行多轮对话**
   - ChatRequest 支持 `conversation_history` 字段
   - 但状态管理还未实现

4. **获得最终准确率数据**
   - 217 个 Ground Truth 实例已有
   - 3 个对比实验脚本已有
   - 但完整的对标测试需要等待 API 集成完成
