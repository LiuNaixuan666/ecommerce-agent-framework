## 💡 关键设计理念

### 1. 分层架构
```
用户 → API 层 → 意图识别 → 知识检索 → 不确定性检测 → LLM 生成 → 用户
```

### 2. 商家隔离
```
每个商家有独立的：
- 产品数据库
- 向量库集合
- 政策文档
→ 完全看不到彼此
```

### 3. 混合数据源
```
语义数据 → 向量库
   ↓
精确数据 → SQL 数据库
   ↓
混合路由器（决定用哪个）
```

### 4. 三维不确定性判断
```
检索置信度（0-1） × (1-歧义度) × 意图置信度
= 总置信度
→ 决定是否澄清
```
